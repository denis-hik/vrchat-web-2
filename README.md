# VRChat Web 2

Personal VR portfolio website showcasing my VRChat experience, worlds, and full VR setup.

The site presents:
- my VRChat worlds
- my VR headset and trackers
- room-scale VR setup and usage
- GIF animations demonstrating movement and transitions

All animations are implemented using GIF sequences, providing a lightweight preview of room-scale interactions. Built with React + TypeScript and optimized for responsive web deployment.
